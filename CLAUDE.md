## Agent skills

### Issue tracker

Issues live in this repo's GitHub Issues (`L26041040/rice-bootstrap`), using the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.

## Branch Policy (provisional)

Do not create or switch to a new Git branch unless the OWNER explicitly approves it. A branch automatically assigned by the Claude Cloud platform is exempt; Claude itself must not create additional branches.
