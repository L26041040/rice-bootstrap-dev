新增：

`scripts/delete_remote_branch.py`

介面保持簡單，例如：

    python3 "<plugin root>/scripts/delete_remote_branch.py" <repo_root> <branch>

行為：

1. 確認 `<repo_root>` 是 git repo
2. 用 `git check-ref-format --branch` 驗證 branch name
3. remote 固定使用 `origin`
4. 找出 origin 的 default branch
5. 禁止刪除：
   - remote default branch
   - `main`
   - `master`
6. branch remote 已不存在時：
   - 視為成功 / idempotent
7. branch 存在時：
   - helper 內部執行 remote delete
   - 不 force
8. 完成後重新讀 remote，確認 branch 確實消失
9. 清楚 stdout 回報成功；失敗則 non-zero + 原因

允許刪除「目前 local checkout 的 branch 在 remote 上的 ref」。
不要因為 local current branch 相同就阻止 remote deletion。
